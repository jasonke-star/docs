Recettes courtes pour les flux de travail PartGenie courants. Utilisez-les comme modèles, puis adaptez-les à votre projet.

## 1. Sélectionnez une pièce avec des preuves

1. Demandez dans * * Recherche**: * Tension de fonctionnement STM32F103C8T6*
2. Ouvrez * * citations de page* * sur la réponse pour vérifier le tableau de la fiche technique
3. Cliquez sur le badge MPN → tiroir de composants → vérifier le stock/prix en direct
4. Enregistrez-le dans la collection si vous le réutilisez

Guides: [Recherche AI] (/fr-FR / recherche ai), [Citations de fiches techniques] (/fr-FR / citations de fiches techniques)

## 2. Remplacer une ligne de nomenclature risquée

1. Passez à * * Travail**, joignez votre nomenclature (CSV / Excel)
2. Demandez: * Analysez les principaux risques de cette nomenclature*
3. Ouvrez des alternatives pour une ligne NRND, confirmez les contraintes d'application si vous y êtes invité
4. ** Adoptez* * un candidat, puis passez en revue * * les changements * * et * * Est. prix**

Guides: [Travail PartGenie] (/en-US / travail partgenie), [Gestion de la nomenclature] (/fr-FR/gestion de la nomenclature), [Alternatives] (/en-US / alternatives)

## 3. Vérifier le coût et l'origine avant d'acheter

1. Ouvrir l'approvisionnement sur le MPN cible-basculer les distributeurs sous Paramètres
2. Cliquez sur * * Acheter* * pour passer à DigiKey / LCSC / Arrow / …
3. Possibilité d'exécuter * * Recherche tarifaire* * pour les importations américaines par pays d'origine

Guides: [Recherche en direct] (/en-US / recherche en direct), [Recherche tarifaire] (/en-US / recherche tarifaire)

## 4. Prototype avec un kit de modules

1. Rechercher un module (par exemple * reCaméra*)
2. Ouvrir le tiroir de produits → Ajouter à la nomenclature ou acheter via * * OpenELAB**
3. Stockez le ZIP de conception de référence dans **Knowledge** et discutez avec lui

Guides: [Modules OpenELAB] (/fr-FR / modules openelab), [Connaissances] (/fr-FR / connaissances)

## 5. Partager un dossier de décision

1. Générer un * * rapport alternatif* *(PDF / Word)pour les parties prenantes
2. ** Partager* * le chat ou la nomenclature par invitation par e-mail
3. Les coéquipiers reçoivent du courrier et ouvrent avec accès à la vue

Guides: [Alternatives](/fr-FR/alternatives), [Partager] (/fr-FR/partager)
