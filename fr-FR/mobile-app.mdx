** PartGenie pour Android est en ligne.** Transportez le même flux de travail électronique IA dans votre poche.

## Scénarios mobiles

- **Enclenchez un composant* — - identifiez les marquages
- **Scanner un PCB* — - trouver des puces à bord
- **Recherche de code SMD* — - lorsque le MPN complet n'est pas imprimé
- **Demandez des fiches techniques**, trouvez des alternatives, obtenez des modèles CAO-alignés sur l'expérience Web
