Les bonnes requêtes obtiennent de meilleures réponses, plus vérifiables. Utilisez ces modèles dans ** Recherche ** ou **Travail**.

## Motif de base

** Type + paramètres clés + contraintes + contexte**

```
Need an N-channel MOSFET, ≥60V, ≥20A, TO-220, for 12V motor drive, industrial temp
```

## Faire / Ne pas

/ Préférer / Éviter |
| --- | --- |
/ MPN exact lorsque vous l'avez (`STM32F103C8T6`) / "un microcontrôleur |”
/ Nombres avec unités (`3.3V`, `1A`, `SOT-23`) / ” petit et pas cher " seulement |
/ Contraintes d'application (`4.5A USB charge`, `automotive`) / Pas de cas d'utilisation lors de la demande d'alternatives |
/ Un objectif par demande / Mélange de cinq demandes non liées |

## Interroger les recettes

** Recherche / spécifications**

```
STM32F103C8T6 operating voltage and absolute maximum ratings
```

** Alternatives* *(attendez-vous à des éclaircissements sur les contraintes)

```
Alternative to BQ24195 for 4.5A USB charging, VQFN preferred
```

** Travail / nomenclature**

```
Analyze top risks from this BOM and suggest adopts for NRND lines
```

** Tarif**

```
Check tariff for 74HC595 made in China entering the US
```

## Après la réponse

- Cliquez sur ** badges de citation** pour vérifier
- Pour les substituts, confirmez ou ignorez la carte de contrainte-le contexte améliore l'ajustement
- Joindre des fichiers de connaissances lorsque la demande dépend de *votre * schéma ou note d'application
