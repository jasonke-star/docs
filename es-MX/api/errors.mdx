# Errors & rate limits

| Status | Meaning |
|---|---|
| 401 | Missing or invalid API key / OAuth token |
| 404 | Unknown `part_id` or expired BOM job |
| 422 | Invalid payload |
| 429 | Quota exceeded |
| 503 | Temporary unavailability |

BOM analysis jobs expire after about one hour in Private Beta. Re-submit if a job is no longer found.

Monthly quotas and response headers are documented under [Authentication](/es-MX/api/authentication).
