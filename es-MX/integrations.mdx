PartGenie se encuentra con usted donde ya trabaja: la aplicación web para proyectos completos, * * Chrome * * en las páginas del distribuidor, * * móvil * * en el banco y * * descargas de ECAD * * o generación de KiCad para el diseño.

Utilice esta página para elegir la conexión correcta. Las guías paso a paso están vinculadas en la tabla.

< Información>

< / Información>

## Flujos típicos

** Abastecimiento → diseño**

1. Explore una pieza en DigiKey o Mouser con la [extensión de Chrome] (/en-US / chrome-extension).
2. Revise alternativas y abra * * Modelos CAD* * o genere KiCad.
3. Importe a su herramienta EDA- [Integración EDA] (/en-US / eda-integration).

** Pregunta → huella**

1. [Buscar] (/en-US / ai-search) la MPN en la aplicación web.
2. Abra el cajón de componentes → **Modelos CAD**, o ejecute [Generación de bibliotecas KiCad] (/en-US / kicad-library).
3. Siga [integración EDA] (/en-US / eda-integration) para su herramienta.

** Banco → escritorio**

1. Identifique una marca con la [aplicación móvil] (/en-US / mobile-app).
2. Continúe con la misma MPN en la búsqueda en la web o en Chrome en la página de un distribuidor.

## Cuenta y créditos

Chrome, web y mobile comparten la misma cuenta PartGenie y el mismo modelo de **créditos**. La generación de KiCad y algunas descargas de ECAD utilizan créditos o facturación adicional como se muestra en [Membresía y precios] (/en-US / membership-pricing).

## Privacidad en sitios compatibles

La extensión de Chrome se activa solo en las páginas de distribuidores y fabricantes compatibles. Utiliza la información de esa página para identificar el componente que está viendo. Consulte [extensión de Chrome] (/en-US / chrome-extension#privacidad y permisos).
