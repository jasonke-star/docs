PartGenie se encuentra con usted donde ya trabaja: la aplicación web para proyectos completos, ** Chrome ** en las páginas del distribuidor, ** móvil ** en el banco y ** descargas de ECAD ** o generación de KiCad para el diseño.

Utilice esta página para elegir la conexión correcta. Las guías paso a paso están vinculadas en la tabla.

## Choose the right integration

| Integration | How it connects | What you can do | EDA / browser open? |
| --- | --- | --- | --- |
| [PartGenie web](/es-MX/getting-started) | Sign in at [app.partgenie.ai](https://app.partgenie.ai) | Search, Work, BOM, Design, Knowledge, KiCad generation, live sourcing | Use while you work in the browser |
| [Chrome extension](/es-MX/chrome-extension) | Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/partgenie/djhpmidamklapnaidbhljfpbnnlninmk), sign in with your PartGenie account | Recognize MPNs on DigiKey, Mouser, LCSC, and other supported pages; chat, alternatives with evidence, ECAD, compare prices | Keep a supported product tab open; sidebar stays beside the listing |
| [Mobile app](/es-MX/mobile-app) | Install **PartGenie** from the App Store or Google Play | Snap parts, scan PCBs, SMD code lookup, search on the go | Use when you are away from your desk |
| [ECAD catalog download](/es-MX/eda-integration#download-catalog-models) | Web or Chrome → open the part → **CAD Models** | Download symbol, footprint, and STEP in formats for Altium, KiCad, Eagle, OrCAD, Allegro, and more (when listed for that MPN) | Open your EDA tool to import the files |
| [KiCad library generation](/es-MX/eda-integration#kicad-import) | Web or Chrome → Search or **CAD models** → generate → **Download** | KiCad 8 `.kicad_sym`, `.kicad_mod`, and 3D with evidence and import checks (Beta) | Open **KiCad 8** to add the library to your project |
| [KiCad plugin](/es-MX/kicad-plugin) | [Settings → Integrations](/es-MX/kicad-plugin#install) → KiCad → install in PCB Editor | Part inspect, BOM sync, BOM health, ECAD generate/request in KiCad | Keep **KiCad** open with the plugin panel |

<Info>
  PartGenie does not replace your EDA license. Catalog downloads and generated KiCad files are imported **into** your existing Altium, KiCad, Eagle, OrCAD, or Allegro workflow. Always verify pitch, pin 1, and pads against the datasheet before fabrication.
</Info>

## Flujos típicos

** Abastecimiento → diseño**

1. Explore una pieza en DigiKey o Mouser con la [extensión de Chrome](/es-MX/chrome-extension).
2. Revise alternativas y abra ** Modelos CAD** o genere KiCad.
3. Importe a su herramienta EDA- [Integración EDA](/es-MX/eda-integration).

** Pregunta → huella**

1. [Buscar](/es-MX/ai-search) la MPN en la aplicación web.
2. Abra el cajón de componentes → **Modelos CAD**, o ejecute [Generación de bibliotecas KiCad](/es-MX/kicad-library).
3. Siga [integración EDA](/es-MX/eda-integration) para su herramienta.

** Banco → escritorio**

1. Identifique una marca con la [aplicación móvil](/es-MX/mobile-app).
2. Continúe con la misma MPN en la búsqueda en la web o en Chrome en la página de un distribuidor.

## Cuenta y créditos

Chrome, web y mobile comparten la misma cuenta PartGenie y el mismo modelo de **créditos**. La generación de KiCad y algunas descargas de ECAD utilizan créditos o facturación adicional como se muestra en [Membresía y precios](/es-MX/membership-pricing).

## Privacidad en sitios compatibles

La extensión de Chrome se activa solo en las páginas de distribuidores y fabricantes compatibles. Utiliza la información de esa página para identificar el componente que está viendo. Consulte [extensión de Chrome](/es-MX/chrome-extension).
