## Before you search

- Prefer a full **MPN** when known; otherwise lead with function + top 3 params
- Attach a datasheet/photo only when it adds information the text lacks
- Use **Search** for Q&A; switch to **Work** once a BOM is in play

## While results load / appear

- Skim the overview, then open **citation badges** (MPN / OEM / distributor / page)
- Check live stock columns when present—don’t assume catalog snapshots are live
- Use follow-ups to tighten package, temp, or firmware constraints

## Alternatives

- Answer the clarification card when you can—context beats raw parametric look-alikes
- Compare 2–5 parts max; export the Alternative report for stakeholders

## Performance habits

- One clear ask per message
- Reuse Collection / Knowledge instead of re-uploading the same PDF
- On Pro, export tables instead of manual copy-paste
