Use this checklist before contacting support. Most account issues resolve with the steps below.

## Can't sign in

1. Confirm the correct email / Google / LinkedIn method you used to register
2. Check caps lock and accidental spaces when pasting passwords
3. Try **Forgot password** and wait a few minutes; check spam
4. Try another browser or an incognito window (extensions can block auth)

Still stuck? Email [support@partgenie.ai](mailto:support@partgenie.ai) with the exact error message and timestamp.

## Email / verification

- Verification mail missing → check spam/promotions; wait 5–10 minutes; resend
- Wrong email used at signup → contact support to correct the account (don't create duplicates)

## Credits & plan

- Credits unexpectedly low → open the header **Credits** panel; confirm monthly allotment vs Top up
- Free vs Pro confusion → see [Membership & pricing](/en-US/membership-pricing); Monthly Pro includes a **7-day trial**
- Top up / upgrade not reflecting → refresh the page; if needed, hard-refresh and re-login

## Language & settings

- UI language wrong → **Settings → Language** (or Auto). See changelog note on multilingual web
- Distributor list empty → **Settings → Distributors**; enable live sources. See [Live sourcing](/en-US/live-sourcing)

## Sharing access

- Invitee didn't get mail → ask them to check spam; resend invite from **Share**
- Link opens but content missing → confirm **Only invited** vs **Public** access. See [Share](/en-US/share)
