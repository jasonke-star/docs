Short recipes for common PartGenie workflows. Use them as templates, then adapt to your project.

## 1. Select a part with evidence

1. Ask in **Search**: *STM32F103C8T6 operating voltage*
2. Open **page citations** on the answer to verify the datasheet table
3. Click the MPN badge → component drawer → check live stock/price
4. Save to Collection if you'll reuse it

Guides: [AI Search](/en-US/ai-search), [Datasheet citations](/en-US/datasheet-citations)

## 2. Replace a risky BOM line

1. Switch to **Work**, attach your BOM (CSV/Excel)
2. Ask: *Analyze top risks from this BOM*
3. Open alternatives for an NRND line, confirm application constraints if prompted
4. **Adopt** a candidate, then review **Changes** and **Est. price**

Guides: [PartGenie Work](/en-US/partgenie-work), [BOM management](/en-US/bom-management), [Alternatives](/en-US/alternatives)

## 3. Cost & origin check before buy

1. Open Procurement on the target MPN—toggle distributors under Settings
2. Click **Purchase** to jump to DigiKey / LCSC / Arrow / …
3. Optionally run **Tariff lookup** for US import by country of origin

Guides: [Live sourcing](/en-US/live-sourcing), [Tariff lookup](/en-US/tariff-lookup)

## 4. Prototype with a module kit

1. Search a module (e.g. *reCamera*)
2. Open the product drawer → Add to BOM or buy via **OpenELAB**
3. Store the reference design ZIP in **Knowledge** and chat against it

Guides: [OpenELAB modules](/en-US/openelab-modules), [Knowledge](/en-US/knowledge)

## 5. Share a decision pack

1. Generate an **Alternative report** (PDF/Word) for stakeholders
2. **Share** the chat or BOM by email invite
3. Teammates receive mail and open with view access

Guides: [Alternatives](/en-US/alternatives), [Share](/en-US/share)
