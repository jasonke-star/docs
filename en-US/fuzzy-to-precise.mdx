You often start with a fuzzy goal (“something for USB charging”). PartGenie helps you narrow it into MPNs, constraints, and project actions.

## A practical loop

1. **State the job** — function + environment (“single-cell Li-ion charger, handheld, 5V USB in”)
2. **Add must-haves** — current, package, interface, temp, certifications
3. **Review candidates** — open citation badges and Procurement
4. **Lock constraints** — when alternatives ask for clarification, confirm what your board must survive
5. **Act** — Adopt into BOM, start Design, or export an Alternative report

## Example

**Fuzzy:** “Need a charger IC like TI’s for a power bank.”

**Better:**

```
Alternative to BQ24195 for portable USB power bank, ≥4.5A charge, I2C, similar thermal package
```

Confirm the constraint card → compare shortlist → Adopt or export report.

## When to switch modes

| Situation | Mode |
| --- | --- |
| Exploring options | **Search** |
| Changing an existing BOM | **Work** |
| Early architecture / initial BOM | **Design** |
| Duty / origin cost | **Tariff lookup** |
