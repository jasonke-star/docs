PartGenie has three ways to get ECAD for a part. Use the one that matches what you need.

| You need | Where |
| --- | --- |
| **Professional** symbol, footprint, and 3D for Altium, Cadence, OrCAD, PADS, and more | Component drawer → **CAD Models** → choose format → **Request** (via [FootprintKu](https://footprintku.com/) partnership) |
| Catalog assets already on file | Same **CAD Models** tab when files are listed for download |
| A KiCad library generated and checked against the datasheet | [KiCad library generation](/en-US/kicad-library) |

## Get a catalog model

<Steps>
  <Step title="Open the part">
    Search the MPN, then click the **MPN badge** in the answer or the part card. That opens the component drawer.
  </Step>
  <Step title="Switch to CAD Models">
    The drawer tabs are **Product**, **Procurement**, and **CAD Models**. Procurement is live price and stock. **CAD Models** is the footprint library for that part.
  </Step>
  <Step title="Pick your EDA format">
    Use the format dropdown (for example **Altium 18**, **Cadence**, **OrCAD**, **PADS**, or **KiCad** when listed).
  </Step>
  <Step title="Request or download">
    Click **Request** for schematic symbol, PCB footprint, or STEP 3D when FootprintKu fulfills professional models for that MPN. Download directly when a catalog file is already available.

    Not every MPN has every format. If nothing is listed, use [KiCad generation](/en-US/kicad-library) instead of guessing a generic 0603.
  </Step>
</Steps>

## When to generate instead

Generate a KiCad library when:

- CAD Models has no file for this exact MPN and package
- You need Symbol + Footprint + STEP together, with an evidence table (pin count, body, pad, pitch) tied to a datasheet page
- You want **KiCad native import** checks before you place the part

Ask in Search:

```
generate verified KiCAD for RC0603FR-071KL
```

Full steps: [KiCad library generation](/en-US/kicad-library).

<Warning>
  A catalog footprint and a generated library can disagree on pad size or pin 1. For anything you will fabricate, check both against the datasheet page, not against each other.
</Warning>
