PartGenie は、CAD シートを置き換えるのではなく、ダウンロード可能なライブラリを通じて EDA ワークフローに接続します。2 つのパス：

- ** カタログモデル **—多くの MPN について、PartGenie にすでにシンボル、フットプリント、および STEP が用意されています。
- **KiCad ジェネレーション (ベータ)** - 証拠とインポートチェックを使用して、データシートから KiCad 8 ライブラリを構築します。

[app.partgenie.ai](https://app.partgenie.ai)、[Chrome extension](/ja-JP/chrome-extension)、または [partgenie.ai](https://www.partgenie.ai/) のパブリックパーツページから開始できます。

## パスを選ぶ

| 必要 | 使用 |
| ---| ---|
MPN のカタログにすでに入っているファイル | [カタログモデルのダウンロード](#download-catalog-models) |
| KiCad 8 シンボル + フットプリント + 証拠付き 3D | [KiCad import](#kicad-import) |
| Altium / Eagle / OrCAD / Allegro | **CAD Models** に記載されているフォーマットをダウンロードし、ツールにインポートする |

カタログと生成ライブラリの詳細:[ECAD & footprints](/ja-JP/ecad-models)。生成の完全なチュートリアル:[KiCad library generation](/ja-JP/kicad-library)。

## カタログモデルのダウンロード

<Steps>
  <Step title="パートを開く">
検索で、**MPN**バッジまたはパーツカードをクリックします。 Chromeで、サポートされている販売代理店ページのサイドバーから**CADモデル**を開きます。
  </Step>
  <Step title="CADモデルを開く">
コンポーネントドロワーでは、タブは**製品**、**調達**、および**CADモデル**です。 **調達**はライブ価格と在庫です。**CADモデル**はフットプリントライブラリです。
  </Step>
  <Step title="フォーマットとダウンロードを選択">
EDA用に提供されているシンボル、フットプリント、および/または3Dファイル（Altium、KiCad、Eagle、OrCAD、Allegroなど）をダウンロードします。 すべてのMPNがすべての形式を持つわけではありません—タブが空の場合は、[KiCad を生成](#kicad-import)またはサポートに連絡してください。
  </Step>
  <Step title="EDAへのインポート">
ダウンロードしたファイルの種類については、仕入先のインポート手順に従ってください。 ライブラリをチームにリリースする前に、ピン1、ピッチ、および中庭をデータシートに対して確認してください。
  </Step>
</Steps>

### Altium デザイナー

1. **CAD Models** から **Altium**(または中立 PCB フットプリント/STEP) アセットをダウンロードします。
2. Altium で、プロジェクトライブラリ (**.PcbLib** / **.SchLib** またはチームが使用する統合ライブラリフロー) にインポートまたはコピーします。
3.スキーマシンボルにフットプリントと 3D モデルを割り当て、通常の DRC を実行します。

KiCad ネイティブファイルのみがある場合は、Altium の KiCad インポーターを使用するか、[KiCad library generation](/ja-JP/kicad-library) 経由で再生成し、チームが承認した移行プロセスを使用して変換します。

### Eagle / Fusion Electronics

**CAD モデル ** にリストされている場合は、Eagle 互換または汎用のフットプリント資産をダウンロードし、Eagle のライブラリエディターまたは Fusion Electronics ライブラリ管理を通じて追加します。

### OrCAD / Allegro

PartGenie が MPN 用にリストするときに OrCAD または Allegro 形式をダウンロードし、Cadence ライブラリパスを介してインポートします。ステップモデルは、フローでサポートされている場合に 3D 衝突チェック用にアタッチされます。

## KiCad のインポート

生成は PartGenie(Web または Chrome) で行われます。**KiCad 8** はターゲット形式です。

<Steps>
  <Step title="ライブラリの生成">
**検索**（動作しない）では、例えば尋ねます:

    ```
    generate verified KiCAD for RC0603FR-071KL
    ```

または、部品ページから**CADモデル**→生成を使用します。 アプリ内通知を待つと、電子メールの生成には数分かかることがあります。
  </Step>
  <Step title="レビューの証拠">
完成したカードを開きます：**シンボル**、**フットプリント**、**3Dモデル**、および**証拠の概要**（計算された対仮定された）。 ダウンロードする前に**Kicadネイティブインポート**、**Pinマッピング**、および**視覚的な監査**を確認してください。
  </Step>
  <Step title="ダウンロード">
ライブラリカードの**ダウンロード**をクリックします。 あなたはKiCad8`を受け取ります。kicad_sym`,'。Kicad_mod`、および3DファイルPartGenieはすでにマシンインポートパスでチェックしました。
  </Step>
  <Step title="KiCadプロジェクトに追加する">
KiCadでは8:

1. シンボルファイルとフットプリントファイルをプロジェクトフォルダまたはグローバルライブラリフォルダ(またはチームが標準化するパス)に配置します。
2. Sym-lib-tableとfp-lib-tableを更新して、kicadが新しいライブラリ名を解決するようにします。
3. ライブラリの再読み込みシンボルエディタまたはフットプリントエディタで、部品を回路図に配置し、フットプリントを関連付けます。
4. 3Dビューアを開き、ボディの高さとピン1をデータシートと比較します。
  </Step>
</Steps>
