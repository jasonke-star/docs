一般的なPartGenieワークフローのための短いレシピ。 それらをテンプレートとして使用して、プロジェクトに適応します。

## 1. エビデンスのある部品を選択する

1. お願い**検索**:*STM32F103C8T6動作電圧*
2. データシートの表を確認するために、回答の**ページ引用**を開きます
3. MPNバッジをクリック→コンポーネントドロワー→ライブの在庫や価格を確認する]
4. 再利用する場合はコレクションに保存します

ガイド:[AI検索](/ja-JP/ai-search)、[データシートの引用](/ja-JP/データシートの引用)

## 2. 危険なBOMラインを置き換える

1. **Work**に切り替え、BOM（CSV/Excel）を添付します。
2. Ask:*このBOMからのトップリスクを分析する*
3. NRND行の代替を開き、プロンプトが表示されたらアプリケーション制約を確認します
4. ***候補者を採用し、**変更**と**Estを確認します。 価格**

ガイド:[PartGenie Work](/ja-JP/partgenie-work)、[BOM管理](/ja-JP/bom-management)、[代替](/ja-JP/alternatives)

## 3. 購入前の費用と起源のチェック

1. ターゲットMPNで調達を開く—設定の下で販売代理店を切り替えます
2. **購入**をクリックしてDigiKey/LCSC/Arrowにジャンプします / …
3. 必要に応じて実行**関税ルックアップ**原産国によって米国の輸入のために

ガイド:[Live sourcing](/ja-JP/live-sourcing)、[Tariff lookup](/ja-JP/tariff-lookup)

## 4. モジュールキット付きプロトタイプ

1. モジュールを検索する(例:*reCamera*)
2. 製品引き出しを開く→BOMに追加するか、**OpenELAB経由で購入します**
3. **Knowledge**にリファレンスデザインのZIPを保存し、それに対してチャットします

ガイド:[OpenELABモジュール](/ja-JP/openelab-modules),[ナレッジ](/ja-JP/knowledge)

## 5. 決定パックを共有する

1. 利害関係者のための**代替レポート**（PDF/Word）を生成します
2. **共有**電子メールの招待によるチャットやBOM
3. チームメイトはメールを受信し、ビューアクセスで開きます

ガイド:[Alternatives](/ja-JP/alternatives),[Share](/ja-JP/share)
