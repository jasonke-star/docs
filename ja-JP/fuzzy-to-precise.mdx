あなたはしばしばあいまいな目標（"USB充電のための何か"）から始めます。 PartGenieを使用すると、Mpn、制約、およびプロジェクトアクションに絞り込むことができます。

##実用的なループ

1. **状態をジョブ**-機能+環境("シングルセルリチウムイオン充電器、ハンドヘルド、5V USBで")
2. **必須項目を追加**-電流、パッケージ、インターフェイス、温度、認定
3. **レビュー候補**-オープン引用バッジと調達
4. **ロック制約**—代替案が明確化を求めるとき、あなたのボードが生き残る必要があるかを確認してくださ
5. **Act**—BOMへの採用、設計の開始、または代替レポートのエクスポート

##例

**Fuzzy:**"力銀行のためのチタニウムのような充電器ICを必要として下さい。”

**より良い:**

```
Alternative to BQ24195 for portable USB power bank, ≥4.5A charge, I2C, similar thermal package
```

制約カードを確認→候補リストを比較→レポートを採用またはエクスポートします。
