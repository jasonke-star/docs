## 검색하기 전

- 알려진 경우 전체 MPN 을 선호합니다. 그렇지 않으면 함수 + 상위 3 개 매개변수로 리드합니다。
- 텍스트에 없는 정보를 추가할 때만 데이터시트/사진 첨부
- Q&A 를 위해 **Search** 를 사용합니다. BOM 이 실행 중일 때 **Work** 로 전환합니다。

## 결과가 로드/표시되는 동안

- 개요를 훑어본 다음 ** 인용 배지 ** 열기 (MPN / OEM / 유통업체 / 페이지)
- 존재할 때 실시간 재고 열 확인 - 카탈로그 스냅샷이 실시간이라고 가정하지 마세요
- 후속 조치를 사용하여 패키지， 임시 또는 펌웨어 제약을 강화합니다。

## 대안

- 가능할 때 명확화 카드에 답변하세요 - 컨텍스트가 원시 매개변수 유사성을 능가합니다
- 최대 2~5 개 부분 비교; 이해관계자를 위한 대안 보고서 내보내기

## 성과 습관

- 메시지당 하나의 명확한 질문
- 동일한 PDF 를 다시 업로드하는 대신 재사용 컬렉션 / 지식
- Pro 에서 수동 복사 붙여넣기 대신 테이블 내보내기
