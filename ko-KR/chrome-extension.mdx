**PartGenie for Chrome** 은 지원되는 유통업체 또는 제조업체 제품 페이지에서 MPN 을 인식합니다. 대체품， 데이터시트 채팅， ECAD 및 가격 비교는 부품 옆의 사이드바에 남아 있으며， 새 탭에 복사하여 붙여넣을 수 없습니다。

[Chrome Web Store] 에서 설치 (https://chromewebstore.google.com/detail/partgenie/djhpmidamklapnaidbhljfpbnnlninmk).

## 설치 및 로그인

<Steps>
<단계 제목=“확장 프로그램 설치”>
[Chrome Web Store 의 PartGenie 목록](https://chromewebstore.google.com/detail/partgenie/djhpmidamklapnaidbhljfpbnnlninmk) 을 열고 **Chrome 에 추가 ** 를 클릭합니다. 자주 사용하는 경우 도구 모음에 PartGenie 아이콘을 고정합니다。
</Step>
<단계 제목=“로그인”>
PartGenie 아이콘을 클릭하거나 지원되는 제품 페이지에서 사이드바를 엽니다. [app.partgenie.ai](https://app.partgenie.ai) 에서 사용하는 것과 동일한 계정으로 로그인합니다。
</Step>
<Step 제목=“지원되는 제품 페이지 열기”>
지원되는 사이트 (예: **DigiKey**, **Mouse** 또는 **LCSC**) 의 제품 세부 정보 페이지로 이동합니다. PartGenie 는 페이지에서 MPN 을 읽고 해당 정확한 부분에 대한 연구를 로드합니다。
</Step>
</Steps>

<Warning>
확장 프로그램은 **supported** 페이지에서만 구성 요소 지원을 실행합니다. 관련 없는 사이트에는 주입되지 않습니다。
</경고>

## 사이드바 사용하기

  <img
    alt="PartGenie Chrome extension on a DigiKey product page: alternatives table, CAD models, Find alternatives, Compare prices, and Ask about this part"
    src="/images/chrome-extension-digikey-sidebar.png"

제품 페이지에서 사이드바가 열리면：

| 제어 | 목적 |
| --- | --- |
| 헤더 (MPN + 소스) | 이 페이지에서 PartGenie 가 일치시킨 부분을 확인합니다 |
| 답변 영역 | 검토할 수 있는 증거가 있는 요약， 사양 및 대체 비교 테이블 |
| **CAD 모델 ** | 이 MPN 의 ECAD 카탈로그로 이동하거나 KiCad 생성을 시작하세요 |
| ** 대안 찾기 ** | 데이터시트와 프로젝트 컨텍스트에 기반한 심층 대체 검색 |
| ** 가격 비교 ** | 교차 유통업체 가격 및 주식 (웹 라이브 소싱과 동일한 정보) |
| ** 이 부분에 대해 물어보기 ** | 개방형 구성 요소에 대해 채팅하기 - 핀아웃， 제한， 대체 |

대안에는 매개변수 테이블뿐만 아니라 지원 증거가 포함됩니다. 프로덕션에서 부품을 교체하기 전에 인용된 소스를 사용하십시오。

## 확장 프로그램의 ECAD

사이드바의 **CAD 모델 ** 에서：

1. **CAD Models** 에 이 MPN 에 대한 파일이 있는 경우 카탈로그에서 기호， 풋프린트 또는 3D 를 다운로드합니다。
2. 또는 **KiCad 라이브러리 생성 **(베타) 을 시작하고 준비되면 다운로드하세요。

EDA 도구의 가져오기 단계: [EDA integration](/ko-KR/eda-integration).

## 전체 웹 앱 열기

사이드바의 링크를 사용하여 ** 전체 PartGenie 구성 요소 페이지 ** 를 열거나 프로젝트， BOM, 디자인 또는 지식이 필요할 때 검색을 계속하십시오。

## 지원되는 사이트

오늘날에는 **DigiKey**, **Mouser** 및 **LCSC** 와 같은 주요 유통업체뿐만 아니라 PartGenie 가 인식하는 추가 제조업체 및 유통업체 페이지가 포함되어 있습니다. 커버리지는 시간이 지남에 따라 확장됩니다. 신뢰하는 페이지가 누락된 경우 [support@partgenie.ai](mailto:support@partgenie.ai) 로 알려주시기 바랍니다。

## 개인정보 보호 및 권한

확장에는 지원되는 제품 페이지에 대한 액세스 권한이 필요하므로 구성 요소를 식별하는 데 필요한 MPN 및 페이지 컨텍스트를 읽을 수 있습니다. 이는 유통업체 로그인을 대체하거나 주문을 대신하지 않습니다. ** 구매 ** 링크는 유통업체의 자체 결제 흐름을 엽니다。

## 문제 해결

| 문제 | 시도 |
| --- | --- |
| 사이드바가 비어 있거나 잘못된 부분 | 제품 페이지 새로 고침; 검색 결과가 아닌 SKU 세부 정보 URL 에 있는지 확인 |
| 로그인 루프 | PartGenie 에 대한 타사 쿠키를 허용하거나 app.partgenie.ai 에 먼저 로그인한 다음 페이지를 다시 로드 |
| 디스트리뷰터에서 확장 프로그램이 누락되었습니다 | 사이트가 아직 지원되지 않을 수 있습니다 - 대신 MPN 과 함께 [Search](/ko-KR/ai-search) 를 사용하십시오 |

더 많은 계정 문제: [계정 문제 해결](/ko-KR/ai-search).
