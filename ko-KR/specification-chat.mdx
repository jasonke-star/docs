구성 요소 데이터 시트와 채팅하여 PDF 를 수동으로 검색하지 않고도 평가， 기능 및 애플리케이션 메모를 가져올 수 있습니다。

## 데이터시트 채팅 시작

1. 검색 결과 또는 컬렉션에서 구성 요소 열기
2. 세부 정보/리소스 영역에서 데이터시트 채팅을 입력합니다 (또는 컨텍스트에서 MPN 을 사용하여 검색에서 요청합니다).
3. 자연어로 질문합니다. 예: * 절대 최대 등급 *, * 권장 운영 조건 *, * 핀 4 의 핀 설명 *

## 페이지 수준 증거

엔진이 테이블이나 값을 인용할 때， 응답에는 ** 페이지 번호 배지 ** 가 포함될 수 있습니다. 클릭하여 PDF 의 해당 페이지로 이동하고 확인합니다. [데이터시트 인용](/ko-KR/datasheet-citations) 을 참조하십시오。

## 자신만의 파일 사용하기

[Knowledge](/ko-KR/knowledge) 에 데이터시트와 앱 메모를 업로드한 다음， 이에 대해 채팅을 실행하여 카탈로그 PDF 뿐만 아니라 엔지니어링 컨텍스트를 사용하여 답변을 제공하세요。

## 팁

- “모든 것을 말해주세요” 보다 정확한 질문 (*ADC 를 사용할 때는 DVD 범위 *) 을 선호합니다。
- 디자인 입력 전에 항상 소스 PDF 에서 중요한 한도를 확인합니다
- MPN 검색을 위해 [AI Search](/ko-KR/ai-search) 와 페어링한 다음， 여기에서 자세히 살펴보세요
