지원팀에 문의하기 전에 이 체크리스트를 사용하십시오. 대부분의 계정 문제는 아래 단계를 통해 해결됩니다。

## 로그인할 수 없음

1. 등록에 사용한 올바른 이메일/Google/LinkedIn 방법을 확인하세요。
2. 암호 붙여넣기 시 대문자 잠금 및 우발적인 공백 확인
3. 비밀번호를 잊어버렸는지 몇 분간 기다려보세요. 스팸을 확인하세요。
4. 다른 브라우저나 익명 창을 사용해 보세요 (확장 프로그램이 인증을 차단할 수 있습니다).

여전히 멈췄나요？ 정확한 오류 메시지와 타임스탬프를 포함하여 이메일 [support@partgenie.ai](mailto:support@partgenie.ai) 을 보내세요。

## 이메일/확인

- 확인 이메일 누락 → 스팸/프로모션 확인; 5-10 분 기다림; 재전송
- 등록 시 잘못된 이메일 사용 → 계정 수정을 위해 지원팀에 문의하기 (중복 생성 안 함)

## 크레딧 및 플랜

- 크레딧이 예상치 못하게 낮음 → 헤더 ** 크레딧 ** 패널 열기; 월별 할당량 확인 vs 업그레이드
- 무료 vs 프로 혼동 → [멤버십 & 가격] 을 참조하세요 (/ko-KR/membership-pricing); 월간 프로에는 **7 일 평가판 ** 이 포함됩니다
- 상위/업그레이드가 반영되지 않음 → 페이지 새로 고침; 필요한 경우 하드 새로 고침 및 다시 로그인

## 언어 및 설정

- UI 언어가 잘못되었습니다 → ** 설정 → 언어 ** (또는 자동). 다국어 웹의 변경 로그 메모 참조
- 디스트리뷰터 목록 비어 있음 → ** 설정 → 디스트리뷰터 **; 라이브 소스 활성화. [Live sourcing](/ko-KR/live-sourcing) 참조

## 공유 액세스

- 초대받은 사람이 이메일을 받지 못했습니다 → 스팸 확인을 요청하세요. **Share** 에서 초대를 다시 보내세요。
- 링크가 열리지만 콘텐츠가 누락됨 → 확인 ** 초대된 사람만 ** vs ** 공개 ** 액세스. [공유](/ko-KR/share) 참조
