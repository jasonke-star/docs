PartGenie 는 전기 특성， 등급 또는 작동 조건을 인용할 때 데이터 시트에서 ** 페이지 수준 증거 ** 를 첨부할 수 있습니다。

## 작동 방식

1. 구성요소 질문하기 (예: *STM32F103C8T6 작동 전압 *)
2. 스펙 값이 ** 페이지 번호 배지 ** 와 함께 표시됨
3. 배지를 클릭하여 해당 페이지에서 데이터시트 PDF 를 엽니다。
4. 표 또는 단락을 확인한 후 대화를 계속합니다。
