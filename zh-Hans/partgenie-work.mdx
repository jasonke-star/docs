**Work** 是首页上的项目模式。上传 BOM、粘贴 part list，或打开已有项目——分析风险、拿替代建议并直接改料，无需离开对话。

## 切换到 Work

在首页输入框选择 **Work**（相对 **Search**）。附加 BOM 文件或粘贴料单，然后提问，例如：

```
Analyze top risks from this BOM.
```

## BOM 项目能做什么

- **风险分析** — EOL/NRND、零库存、无采购数据、厂商缺失
- **BOM 健康报告** — 器件分布、风险数量、建议下一步
- **替代料** — 推荐并 **Adopt** 进项目
- **带上下文对话** — 引用选中的 BOM 行，服务供应链决策

## Design 项目

Work 也覆盖 **Design**：概念设计、架构图、初始 BOM、技术方案。详见 [Design 模式](/zh-Hans/design-mode)。

## 小提示

- 目标是改项目时用 **Work**；开放式器件问答用 **Search**
- Adopt 后，锁定版本前先看 [BOM Changes / 预估价格](/zh-Hans/bom-management)
