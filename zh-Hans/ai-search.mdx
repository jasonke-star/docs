PartGenie 搜索面向硬件工程师，不是通用聊天。回答基于器件数据、规格书与实时来源，**可核验、可溯源**。

## 你可以问什么

- **MPN 查询** — 精确料号、近匹配、厂商联想
- **规格与应用** — 电压、封装、场景选型
- **替代料** — 结合项目上下文推荐（见 [替代料](/zh-Hans/alternatives)）
- **模组与套件** — 开发板、机器人部件等（见 [OpenELAB](/zh-Hans/openelab-modules)）

```
示例：
- "STM32F103C8T6 工作电压"
- "BQ24195 替代料，4.5A USB 充电"
- "100uF 16V 电解电容，车规"
```

## 如何搜索

<Steps>
  <Step title="打开首页">
    访问 [app.partgenie.ai](https://app.partgenie.ai)。器件问答用 **Search**；对 BOM/Design 项目分析执行用 **Work**。
  </Step>
  <Step title="输入查询">
    自然语言、粘贴 MPN、上传规格书/图片，或使用搜索框中的**语音输入**。
  </Step>
  <Step title="阅读回答">
    含器件卡片、表格与**引用角标**。灰色 MPN 角标打开器件抽屉；绿 = 原厂、橙 = 分销商、紫 = 社区。
  </Step>
  <Step title="继续追问">
    可使用追问建议——包括一键 **Design**，基于当前器件启动硬件设计。
  </Step>
</Steps>

## 可验证的回答

大多数 AI 只给文字。PartGenie 会引用**具体 MPN**与**来源链接**，设计导入前可自行核对：

- 点击 MPN 角标 → 器件抽屉（规格、库存、价格）
- 点击分销商角标 → 跳转采购页
- 规格书结论可带**页码级引用**（见 [规格书页码溯源](/zh-Hans/datasheet-citations)）
