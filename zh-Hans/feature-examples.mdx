以下是常见 PartGenie 工作流的简短配方，可按项目改写。

## 1. 带证据选型

1. 在 **Search** 提问：*STM32F103C8T6 工作电压*
2. 点击回答中的**页码引用**核对规格书表格
3. 点击 MPN 角标 → 器件抽屉 → 查看实时库存/价格
4. 需要复用时加入 Collection

文档：[AI 智能搜索](/zh-Hans/ai-search)、[规格书页码溯源](/zh-Hans/datasheet-citations)

## 2. 替换 BOM 风险行

1. 切换 **Work**，附加 BOM（CSV/Excel）
2. 提问：*Analyze top risks from this BOM*
3. 对 NRND 行打开替代料，按提示确认应用约束
4. **Adopt** 候选料，再看 **Changes** 与 **Est. price**

文档：[PartGenie Work](/zh-Hans/partgenie-work)、[BOM 管理](/zh-Hans/bom-management)、[替代料](/zh-Hans/alternatives)

## 3. 下单前做成本与产地核对

1. 打开目标 MPN 的 Procurement，在设置中开关分销商
2. 点击 **Purchase** 跳转 DigiKey / LCSC / Arrow 等
3. 如需，用 **Tariff lookup** 按原产国估算美国进口关税

文档：[实时采购](/zh-Hans/live-sourcing)、[关税查询](/zh-Hans/tariff-lookup)

## 4. 用模组套件做原型

1. 搜索模组（如 *reCamera*）
2. 打开产品抽屉 → Add to BOM，或经 **OpenELAB** 采购
3. 把参考设计 ZIP 存进 **Knowledge**，并针对文件对话

文档：[OpenELAB 模组](/zh-Hans/openelab-modules)、[Knowledge](/zh-Hans/knowledge)

## 5. 分享决策包

1. 生成 **Alternative report**（PDF/Word）给相关方
2. 用邮箱邀请 **Share** 对话或 BOM
3. 同事收到邮件后按查看权限打开

文档：[替代料](/zh-Hans/alternatives)、[分享](/zh-Hans/share)
