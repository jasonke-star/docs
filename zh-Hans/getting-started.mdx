## 快速开始

<Frame>
  <img src="/images/auto/homepage.png" alt="PartGenie 首页：Search / Work，以及 Optimize BOM、Design、Tariff lookup" />
</Frame>

<Steps>
  <Step title="注册账户">
    打开 [app.partgenie.ai](https://app.partgenie.ai) 或 [partgenie.cn](https://partgenie.cn)，使用邮箱 / Google / LinkedIn（国内也可手机号、微信）登录。

    <Frame>
      <img src="/images/zh-Hans/login.png" alt="PartGenie 登录界面" />
    </Frame>
  </Step>
  <Step title="完善资料">
    填写角色与行业，便于更贴合的推荐。
  </Step>
  <Step title="第一次搜索">
    保持 **Search**，输入 MPN 或自然语言：

    ```
    STM32F103C8T6 工作电压
    BQ24195 替代料
    100uF 16V 电解电容
    ```

    也可用**语音**、附加文件/图片，或点选推荐提示。
  </Step>
</Steps>

## 首页模式

| 控件 | 用途 |
| --- | --- |
| **Search** | 器件问答、替代料、引用核验 |
| **Work** | 对已附加 BOM/Design 分析并执行 |
| **Optimize BOM** | 进入 BOM 健康 / 风险流程 |
| **Design Hardware** | 启动 Design（Beta） |
| **Tariff lookup** | 按原产国估算美国进口关税 |

详见：[AI 智能搜索](/zh-Hans/ai-search) · [PartGenie Work](/zh-Hans/partgenie-work)

## 第一次回答之后

1. 点击 **MPN / 页码引用角标** 核验来源 — [规格书页码溯源](/zh-Hans/datasheet-citations)
2. 打开器件抽屉 → **Procurement** 看实时价库 — [实时采购](/zh-Hans/live-sourcing)
3. 继续追问，或从对话进入 **Design** — [Design 模式](/zh-Hans/design-mode)

## 几分钟内做第一个 BOM

1. 切换到 **Work**（或 Optimize BOM），上传 CSV/Excel / 粘贴 part list
2. 提问：`Analyze top risks from this BOM`
3. 查看健康报告、Adopt 替代料，检查 **Changes** 与 **Est. price**

文档：[BOM 管理](/zh-Hans/bom-management) · [功能示例](/zh-Hans/feature-examples)

## 侧边栏常用入口

- **Projects** — BOM 与 Design 工作区
- **Knowledge** — 文件与 AI 产物
- **Collection** — 收藏器件
- 顶部 **Credits** — 余额、Top up、套餐 — [会员与定价](/zh-Hans/membership-pricing)

## 建议尽早打开的设置

- **Language** — Auto 或指定语言
- **Distributors** — 开关实时数据源
- 通知 — 邮件 / 站内偏好
