联系支持前，先按下面清单自查。多数账户问题可自行解决。

## 无法登录

1. 确认注册时使用的方式（邮箱 / Google / LinkedIn 等）
2. 检查大小写、粘贴密码时是否带空格
3. 使用**忘记密码**，等待几分钟并检查垃圾邮件
4. 换浏览器或无痕模式（扩展可能拦截登录）

仍失败？发邮件至 [support@partgenie.ai](mailto:support@partgenie.ai)，附上完整报错与大概时间。

## 邮箱 / 验证

- 收不到验证邮件 → 查垃圾箱/促销箱；等 5–10 分钟；重发
- 注册邮箱填错 → 联系支持更正，避免再建一个重复账号

## Credits 与套餐

- Credits 异常偏低 → 打开顶部 **Credits** 面板，核对月额度与 Top up
- Free / Pro 混淆 → 见 [会员与定价](/zh-Hans/membership-pricing)；Monthly Pro 含 **7 天试用**
- Top up / 升级未生效 → 刷新页面；必要时强制刷新后重新登录

## 语言与设置

- 界面语言不对 → **设置 → Language**（或 Auto）
- 分销商列表为空 → **设置 → Distributors** 打开 Live sources。见 [实时采购](/zh-Hans/live-sourcing)

## 分享权限

- 受邀人未收到邮件 → 请对方查垃圾箱；在 **Share** 中重发
- 链接能开但内容不对 → 确认是 **仅受邀** 还是 **公开链接**。见 [分享](/zh-Hans/share)
