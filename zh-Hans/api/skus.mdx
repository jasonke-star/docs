# Product SKUs

| SKU | Who | Endpoints |
|---|---|---|
| **A Catalog** | ERP / PLM / EMS / partner embeds | `lookup`, `batch-lookup`, `search`, `GET part`, `offers`, `offers/cached`, partner availability |
| **B Intelligence** | Decision / agent / BOM workflows | `resolve`, `alternatives`, `bom/analyze`, `claims`, `engineering-profile` |

Availability signals ship **inside Catalog** (not a separate paid SKU). ECAD API is **deferred** (not in current docs or pricing).

## Evidence packaging

- **Catalog** `GET /v1/parts/{id}` may include `has_claims`, `has_engineering_profile`, and `evidence_links`.
- **Intelligence** returns claim / profile **bodies**. Without Intelligence → `403`.
