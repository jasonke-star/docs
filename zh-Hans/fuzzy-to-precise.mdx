很多时候需求是模糊的（“要个 USB 充电相关的”）。PartGenie 帮你收敛到 MPN、约束和可执行动作。

## 实用循环

1. **说清任务** — 功能 + 环境（“单节锂电池充电，手持，5V USB 输入”）
2. **补上硬性条件** — 电流、封装、接口、温区、认证
3. **审候选** — 打开引用角标与 Procurement
4. **锁定约束** — 替代料弹出澄清时，确认板级必须满足的条件
5. **落地** — Adopt 进 BOM、启动 Design，或导出 Alternative Report

## 示例

**模糊：** “要个类似 TI 的充电宝充电芯片。”

**更好：**

```
BQ24195 替代料，便携 USB 充电宝，≥4.5A 充电，I2C，相近散热封装
```

确认约束卡片 → 对比短名单 → Adopt 或导出报告。

## 何时切换模式

| 场景 | 模式 |
| --- | --- |
| 探索方案 | **Search** |
| 改已有 BOM | **Work** |
| 早期架构 / 初始 BOM | **Design** |
| 关税 / 产地成本 | **Tariff lookup** |
