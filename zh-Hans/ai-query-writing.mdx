提问越清楚，回答越可核验。在 **Search** 或 **Work** 中可用以下模式。

## 核心结构

**类型 + 关键参数 + 约束 + 场景**

```
需要 N 沟道 MOSFET，≥60V，≥20A，TO-220，用于 12V 电机驱动，工业温区
```

## 建议 / 避免

| 更推荐 | 尽量避免 |
| --- | --- |
| 有料号就写全 (`STM32F103C8T6`) | 只说“要一个单片机” |
| 带单位的数字 (`3.3V`、`1A`、`SOT-23`) | 只有“又小又便宜” |
| 应用约束 (`4.5A USB 充电`、车规) | 找替代料却不说使用场景 |
| 一次一个目标 | 一条里塞五个无关问题 |

## 提问配方

**查询 / 规格**

```
STM32F103C8T6 工作电压与绝对最大额定值
```

**替代料**（可能弹出约束确认）

```
BQ24195 替代料，4.5A USB 充电，优先 VQFN
```

**Work / BOM**

```
Analyze top risks from this BOM，并对 NRND 行给出 Adopt 建议
```

**关税**

```
Check tariff for 74HC595 made in China entering the US
```

## 拿到回答之后

- 点击**引用角标**核验
- 找替代时确认或跳过约束卡片——上下文越好，结果越贴
- 依赖你自己的原理图/笔记时，先附加 Knowledge 文件
