拿到 ECAD 有三条路，按你要的东西选。

| 你要的 | 入口 |
| --- | --- |
| **专业级** symbol、footprint、3D（Altium、Cadence、OrCAD、PADS 等） | 器件抽屉 → **CAD Models** → 选格式 → **Request**（与 [FootprintKu](https://footprintku.com/) 合作） |
| 目录里已有、可直接下载的文件 | 同一 **CAD Models** 页签 |
| 对照规格书生成并校验过的 KiCad 库 | [KiCad 库生成](/zh-Hans/kicad-library) |

## 下载目录模型

<Steps>
  <Step title="打开器件">
    搜索 MPN，点击回答里的 **MPN 角标**或器件卡片，打开器件抽屉。
  </Step>
  <Step title="切到 CAD Models">
    抽屉页签是 **Product**、**Procurement**、**CAD Models**。Procurement 是实时价格和库存。**CAD Models** 是这颗料的封装库。
  </Step>
  <Step title="选择 EDA 格式">
    在格式下拉里选 **Altium 18**、**Cadence**、**OrCAD**、**PADS** 或列出的 **KiCad** 等。
  </Step>
  <Step title="Request 或下载">
    对 schematic symbol、PCB footprint、STEP 3D 点 **Request**，由 FootprintKu 交付该 MPN 的专业模型；若目录里已有文件则直接下载。

    申请可能需要等待——就绪后会收到**站内通知**与**邮件**（若已开启）。见 [通知设置](/zh-Hans/account-management#通知)。

    不是每颗 MPN 都有全部格式。若为空，请走 [KiCad 生成](/zh-Hans/kicad-library)，不要用通用 0603 凑合。
  </Step>
</Steps>

## 什么时候改为生成

下面情况用 KiCad 生成：

- CAD Models 里没有这颗精确 MPN 和封装的文件
- 你要 Symbol、Footprint、STEP 一起给，并且每项能对上规格书页码（引脚数、本体、焊盘、pitch）
- 你要在摆进原理图之前看到 **KiCad native import** 一类校验

在 Search 里输入：

```
generate verified KiCAD for RC0603FR-071KL
```

完整步骤见 [KiCad 库生成](/zh-Hans/kicad-library)。

<Warning>
  目录封装和生成库可能在焊盘或 Pin 1 上不一致。要投板的料，以规格书对应页为准，不要只拿两个文件互相比较。
</Warning>
