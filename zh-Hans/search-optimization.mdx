## 搜索前

- 有完整 **MPN** 就直接用；否则用「功能 + 最重要的 3 个参数」开头
- 只有文字说不清时再附加规格书/照片
- 问答用 **Search**；BOM 已上场就切 **Work**

## 结果出现时

- 先看概览，再点开**引用角标**（MPN / 原厂 / 分销商 / 页码）
- 有实时库存列时再下采购判断——Catalog snapshot ≠ Live
- 用追问收紧封装、温区或固件约束

## 替代料

- 尽量填写澄清卡片——上下文好过纯参数相似
- 对比控制在 2–5 颗；需要同步他人时导出 Alternative Report

## 效率习惯

- 一条消息一个目标
- 复用 Collection / Knowledge，避免重复上传同一 PDF
- Pro 可导出表格，少用手工拷贝
