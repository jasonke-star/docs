**PartGenie Android App 已正式上线。** 把与 Web 对齐的 AI 电子工作流装进口袋。

## 移动端场景

- **拍照查 marking** — 识别器件丝印
- **拍 PCB 找芯片** — 板上器件一拍即查
- **SMD code 查询** — 没有完整料号也能定位
- **问规格书、找替代料、获取 CAD** — 体验对齐 Web
