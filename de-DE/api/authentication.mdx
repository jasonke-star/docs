# Authentication

## Public `/v1`

```http
Authorization: Bearer pg_test_…
Authorization: Bearer pg_live_…
Authorization: Bearer pg_at_…   # OAuth access token
```

Issue credentials in the [developer portal](https://developers.partgenie.ai). Legacy env allow-list `PARTGENIE_API_KEYS` still works for Pilot.

See also [OAuth client_credentials](/de-DE/api/oauth).

Quota headers on responses:

- `X-RateLimit-PartReturn-Limit` / `-Remaining`
- `X-RateLimit-LiveOffer-Limit` / `-Remaining`
- `X-RateLimit-Period` (`YYYY-MM`)

HTTP **429** when exceeded (no silent truncation).
