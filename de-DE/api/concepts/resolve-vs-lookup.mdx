# Resolve vs Lookup

| | `POST /parts/resolve` | `POST /parts/lookup` |
|---|---|---|
| Input | Dirty MPN, NL, ambiguous | Known MPN |
| Output | candidates + confidence (+ rationale / match_hints for NL) | Single part + `part_id` |
| ES | Search / lookup helpers | Deterministic catalog lookup only |

Never call Elasticsearch from the sourcing brand — only these endpoints.
