# Resolve vs Lookup

| | `POST /parts/resolve` | `POST /parts/lookup` |
|---|---|---|
| Input | Dirty MPN, NL, ambiguous | Known MPN |
| Output | candidates + confidence (+ rationale / match_hints for NL) | Single part + `part_id` |
| Best for | Messy or natural-language input | Exact catalog match |

Use these endpoints for identity — do not scrape or reverse-engineer catalog storage.
