# PartGenie Catalog & Intelligence API

Self-serve at [developers.partgenie.ai](https://developers.partgenie.ai). SKUs: **Catalog** (includes Availability signals) and **Intelligence** (+ Evidence).

| You get | You do not get |
|---|---|
| What is this part? | Landed customer quotes |
| Observed market stock/price | PO / payment / logistics |
| Alternatives with objectives | Order / checkout APIs |
| BOM risk + resolve + claims/profile | Full PartGenie Chat transcript / ECAD API |

PartGenie App and third-party integrations call the same `partgenie_intel` core. REST and MCP are adapters only.
