提問越清楚，回答越可核驗。在 **Search** 或 **Work** 中可用以下模式。

## 核心結構

**類型 + 關鍵參數 + 約束 + 場景**

```
需要 N 溝道 MOSFET，≥60V，≥20A，TO-220，用於 12V 電機驅動，工業溫區
```

## 建議 / 避免

| 更推薦 | 儘量避免 |
| --- | --- |
| 有料號就寫全 (`STM32F103C8T6`) | 只說“要一個單片機” |
| 帶單位的數字 (`3.3V`、`1A`、`SOT-23`) | 只有“又小又便宜” |
| 應用約束 (`4.5A USB 充電`、車規) | 找替代料卻不說使用場景 |
| 一次一個目標 | 一條裡塞五個無關問題 |

## 提問配方

**查詢 / 規格**

```
STM32F103C8T6 工作電壓與絕對最大額定值
```

**替代料**（可能彈出約束確認）

```
BQ24195 替代料，4.5A USB 充電，優先 VQFN
```

**Work / BOM**

```
Analyze top risks from this BOM，並對 NRND 行給出 Adopt 建議
```

**關稅**

```
Check tariff for 74HC595 made in China entering the US
```

## 拿到回答之後

- 點擊**引用角標**核驗
- 找替代時確認或跳過約束卡片——上下文越好，結果越貼
- 依賴你自己的原理圖/筆記時，先附加 Knowledge 文件
