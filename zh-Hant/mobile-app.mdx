**PartGenie Android App 已正式上線。** 把與 Web 對齊的 AI 電子工作流裝進口袋。

## 移動端場景

- **拍照查 marking** — 識別器件絲印
- **拍 PCB 找芯片** — 板上器件一拍即查
- **SMD code 查詢** — 沒有完整料號也能定位
- **問規格書、找替代料、獲取 CAD** — 體驗對齊 Web
