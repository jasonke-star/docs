**Work** 是首頁上的項目模式。上傳 BOM、粘貼 part list，或打開已有項目——分析風險、拿替代建議並直接改料，無需離開對話。

## 切換到 Work

在首頁輸入框選擇 **Work**（相對 **Search**）。附加 BOM 文件或粘貼料單，然後提問，例如：

```
Analyze top risks from this BOM.
```

## BOM 項目能做什麼

- **風險分析** — EOL/NRND、零庫存、無採購數據、廠商缺失
- **BOM 健康報告** — 器件分佈、風險數量、建議下一步
- **替代料** — 推薦並 **Adopt** 進項目
- **帶上下文對話** — 引用選中的 BOM 行，服務供應鏈決策

## Design 項目

在 Work 裡，設計按階段打開：**Brief**、**Plan**、**Architecture**、**BOM**、**Image**。在 Plan 裡選定方案（其中一個是 **Active**），再 **Use** 或 **Export**。圖片可以有多個視角。詳見 [Design 模式](/zh-Hant/design-mode)。

## 小提示

- 目標是改項目時用 **Work**；開放式器件問答用 **Search**
- Adopt 後，鎖定版本前先看 [BOM Changes / 預估價格](/zh-Hant/bom-management)
