聯繫支持前，先按下面清單自查。多數帳戶問題可自行解決。

## 無法登入

1. 確認註冊時使用的方式（郵箱 / Google / LinkedIn 等）
2. 檢查大小寫、粘貼密碼時是否帶空格
3. 使用**忘記密碼**，等待幾分鐘並檢查垃圾郵件
4. 換瀏覽器或無痕模式（擴展可能攔截登入）

仍失敗？發郵件至 [support@partgenie.ai](mailto:support@partgenie.ai)，附上完整報錯與大概時間。

## 郵箱 / 驗證

- 收不到驗證郵件 → 查垃圾箱/促銷箱；等 5–10 分鐘；重發
- 註冊郵箱填錯 → 聯繫支持更正，避免再建一個重複賬號

## Credits 與套餐

- Credits 異常偏低 → 打開頂部 **Credits** 面板，核對月額度與 Top up
- Free / Pro 混淆 → 見 [會員與定價](/zh-Hant/membership-pricing)；Monthly Pro 含 **7 天試用**
- Top up / 升級未生效 → 刷新頁面；必要時強制刷新後重新登入

## 語言與設定

- 界面語言不對 → **設定 → Language**（或 Auto）
- 分銷商列表為空 → **設定 → Distributors** 打開 Live sources。見 [實時採購](/zh-Hant/live-sourcing)

## 分享權限

- 受邀人未收到郵件 → 請對方查垃圾箱；在 **Share** 中重發
- 連結能開但內容不對 → 確認是 **僅受邀** 還是 **公開連結**。見 [分享](/zh-Hant/share)
