<Update label="2026-10-28" tags={["Workspace", "首頁", "導航"]} description="首頁工作臺與更清晰的側欄 IA（Projects、Watch、Library）">
  <Frame>
    <img

  **登入後的首頁改為「工作臺」，不再只有居中搜索框。** 在 [app.partgenie.ai](https://app.partgenie.ai) 登入後會看到時段問候、**三列卡片**和底部 **Explore PartGenie** 輪播（BOM、Design、替代料、關稅查詢、演示等入口）。某一列還沒有數據時，會顯示**引導卡片**，一鍵進入 Search、新建 BOM、[AI Watch](/zh-Hant/changelog#2026-10-27) 或 RFQ；有活動後同一位置切換為**數據卡片**——最近的 **Projects**、**Tasks**（Search / Work / BOM / Design / Watch 會話）、**Watch 命中**與**進行中的 RFQ**，每列最多五行並可快速續聊。列表加載時使用骨架屏佔位。

  **側欄資訊架構**按實際工作流重新分組：

  | 區域 | 變化 |
  | --- | --- |
  | **Search** | 仍是預設入口；**⌘K** 可搜對話、Knowledge 與 Projects。 |
  | **Watch** | 獨立入口，**Findings** 與 **Watch** 分頁（不再與 Collection 混在同一頁）。 |
  | **Collection** | 收藏的器件、品牌與書籤；列表與詳情並排查看。 |
  | **Projects** | 側欄 **Projects** 進入**硬件項目**中心；可展開最近項目，支持排序、置頂、重命名、複製或刪除。 |
  | **Library** | 團隊 **Parts library** 與審批；**Launch** 回到 Library 下，用於連接器安裝。 |
  | **Sourcing** | 團隊工作區在 Library 上方展示 **Sourcing / RFQs**（啟用採購時）。 |

  **硬件項目（Hardware projects）** 將 **Design 與 BOM 收進同一項目殼**：在項目頁可篩選排序、切換**卡片/列表**、查看 **Architecture** 與設計圖、閱讀 **BOM health findings**、查看 **BOM 估價趨勢**，並**發起或繼續 RFQ**。無論 BOM 來自 CSV、對話還是 design sync，導入都會保留位號。

  **Workspace 體驗**同步收緊：未激活/空工作區卡片在 **設定 → Workspace** 中更清晰； onboarding 完成後直接進入工作臺（可選團隊邀請）；在當前頁面即可 **New watch** / **RFQ**。參見 [快速開始](/zh-Hant/getting-started) · [BOM 管理](/zh-Hant/bom-management) · [Collection](/zh-Hant/favorites)。
</Update>

  **AI Watch** 把某個 **器件** 或 **廠商** 變成一條 **監控任務**——由 PartGenie 在後臺跟蹤關鍵變化，不必每天手動刷分銷頁。

  在 **Search** 打開器件結果頁，點擊頁面上方的 **Start a watch**（開始監控）。用自然語言說明要盯什麼（例如 **EOL**、**PCN**、**價格**、**庫存**、**交期**、**替代料**），選擇 **Daily** 頻率與本地通知時間，再 **Start watch**。任務集中在側欄 **Watch**：**Findings** 查看命中變化，**Watch** 標籤頁可 **Pause**、**Edit task** 或核對計劃。

  適合 BOM 里長期使用的 MPN、單一貨源料號，或任何需要在 PCN / 行情波動時及時介入、又不想被無效提醒打擾的場景。
</Update>

  **Search 現已內置工程計算器。** PartGenie 會根據問題匹配 Audit 面板、展示公式，並在有明確極限時給出 **Pass / Fail** 檢查。

  **當前已上線的計算器：**

  | 面板 | 用途 |
  | --- | --- |
  | **Resistor power rating audit** | P = V²/R（或 VI / I²R），相對額定功率的 margin |
  | **Power dissipation & junction temperature** | LDO Pd、Tj = Ta + Pd × θJA 對比上限——**Electrical** / **Thermal** 檢查 |

  **示例 query：** `100Ω resistor at 12V — is 0.25W rating enough?` · `Rough estimate: how much heat does a 3.3V LDO drop from 12V at 200mA?` · `12V 轉 3.3V 400mA，θJA 50°C/W，熱校核過不過？`

  更多問法見 [工程計算器](/zh-Hant/engineering-calculator)。

  回答裡附帶 **Intelligent UI**：**Try different inputs** 滑條**本地重算**，不另佔 Search。問題不完整時也會**自主調參**（例如在標稱電流之上做應力估算）。
</Update>
