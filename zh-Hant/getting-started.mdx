      <img src="/images/zh-Hant/login.png" alt="PartGenie 登入界面" />

  <Step title="完善資料">
    填寫角色與行業，便於更貼合的推薦。
  </Step>
  <Step title="第一次搜索">
    保持 **Search**，輸入 MPN 或自然語言：

    ```
    STM32F103C8T6 工作電壓
    BQ24195 替代料
    100uF 16V 電解電容
    ```

    也可用**語音**、附加文件/圖片，或點選推薦提示。
  </Step>
</Steps>

## 首頁模式

| 控件 | 用途 |
| --- | --- |
| **Search** | 器件問答、替代料、引用核驗 |
| **Work** | 對已附加 BOM/Design 分析並執行 |
| **Optimize BOM** | 進入 BOM 健康 / 風險流程 |
| **Design Hardware** | 啟動 Design（Beta） |
| **Tariff lookup** | 按原產國估算美國進口關稅 |

詳見：[AI 智能搜索](/zh-Hant/ai-search) · [PartGenie Work](/zh-Hant/partgenie-work)

## 第一次回答之後

1. 點擊 **MPN / 頁碼引用角標** 核驗來源 — [規格書頁碼溯源](/zh-Hant/datasheet-citations)
2. 打開器件抽屜 → **Procurement** 看實時價庫 — [實時採購](/zh-Hant/live-sourcing)
3. 繼續追問，或從對話進入 **Design** — [Design 模式](/zh-Hant/design-mode)

## 幾分鐘內做第一個 BOM

1. 切換到 **Work**（或 Optimize BOM），上傳 CSV/Excel / 粘貼 part list
2. 提問：`Analyze top risks from this BOM`
3. 查看健康報告、Adopt 替代料，檢查 **Changes** 與 **Est. price**

文檔：[BOM 管理](/zh-Hant/bom-management) · [功能示例](/zh-Hant/feature-examples)

## 側邊欄常用入口

- **Search** — 器件問答；**⌘K** 可搜對話、Knowledge 與 Projects
- **Watch** — 監控任務與 **Findings**
- **Collection** — 收藏的器件與品牌
- **Projects** — 硬件項目（BOM + Design 同一項目殼）
- **Library** — Knowledge 文件；團隊工作區下為 **Parts library**；**Launch** 安裝連接器
- 頂部 **Credits** — 餘額、Top up、套餐 — [會員與定價](/zh-Hant/membership-pricing)

## 建議儘早打開的設定

- **Language** — Auto 或指定語言
- **Distributors** — 開關實時數據源
- 通知 — 郵件 / 站內偏好
