很多時候需求是模糊的（“要個 USB 充電相關的”）。PartGenie 幫你收斂到 MPN、約束和可執行動作。

## 實用循環

1. **說清任務** — 功能 + 環境（“單節鋰電池充電，手持，5V USB 輸入”）
2. **補上硬性條件** — 電流、封裝、接口、溫區、認證
3. **審候選** — 打開引用角標與 Procurement
4. **鎖定約束** — 替代料彈出澄清時，確認板級必須滿足的條件
5. **落地** — Adopt 進 BOM、啟動 Design，或導出 Alternative Report

## 示例

**模糊：** “要個類似 TI 的充電寶充電芯片。”

**更好：**

```
BQ24195 替代料，便攜 USB 充電寶，≥4.5A 充電，I2C，相近散熱封裝
```

確認約束卡片 → 對比短名單 → Adopt 或導出報告。

## 何時切換模式

| 場景 | 模式 |
| --- | --- |
| 探索方案 | **Search** |
| 改已有 BOM | **Work** |
| 早期架構 / 初始 BOM | **Design** |
| 關稅 / 產地成本 | **Tariff lookup** |
