PartGenie 出現在你本來就在用的地方：**網頁**做完整項目，**Chrome** 在分銷商商品頁旁，**手機**在工位，**ECAD** 下載或 KiCad 生成進 layout。

本頁用表格幫你選對集成方式；分步教程見各連結。

## 選對集成方式

| 集成 | 如何連接 | 能做什麼 | 要不要開著 EDA / 瀏覽器 |
| --- | --- | --- | --- |
| [PartGenie 網頁](/zh-Hant/getting-started) | 登入 [app.partgenie.ai](https://app.partgenie.ai) | Search、Work、BOM、Design、Knowledge、KiCad 生成、實時採購 | 用網頁時保持瀏覽器即可 |
| [Chrome 擴展](/zh-Hant/chrome-extension) | 從 [Chrome 網上應用店](https://chromewebstore.google.com/detail/partgenie/djhpmidamklapnaidbhljfpbnnlninmk) 安裝，用 PartGenie 賬號登入 | 在 DigiKey、Mouser、LCSC 等支持頁面識別 MPN；對話、帶依據的替代料、ECAD、比價 | 保持支持站點的商品頁打開；側邊欄貼在頁面旁 |
| [移動端 App](/zh-Hant/mobile-app) | App Store / Google Play 安裝 **PartGenie** | 拍照識件、掃 PCB、SMD code、移動搜索 | 離開工位時用 |
| [ECAD 目錄下載](/zh-Hant/eda-integration#download-catalog-models) | 網頁或 Chrome → 打開器件 → **CAD Models** | 下載 symbol、footprint、STEP（該 MPN 有庫時），格式可覆蓋 Altium、KiCad、Eagle、OrCAD、Allegro 等 | 在 EDA 裡導入文件 |
| [KiCad 庫生成](/zh-Hant/eda-integration#kicad-import) | 網頁或 Chrome → Search 或 **CAD models** → 生成 → **Download** | KiCad 8 的 `.kicad_sym`、`.kicad_mod`、3D，帶證據與導入校驗（Beta） | 打開 **KiCad 8** 把庫加進工程 |
| [KiCad 插件](/zh-Hant/kicad-plugin) | [設定 → 集成](/zh-Hant/kicad-plugin#安裝) → KiCad → 裝入 PCB 編輯器 | Part inspect、BOM 同步、BOM health、ECAD 生成/申請 | 保持 **KiCad** 與插件面板打開 |

<Info>
  PartGenie 不替代你的 EDA 授權。目錄下載與 KiCad 生成文件都是**導入**到現有 Altium、KiCad、Eagle、OrCAD、Allegro 流程裡。量產前務必對照規格書核對 pitch、Pin 1 與焊盤。
</Info>

## 常見路徑

**採購 → 設計**

1. 在 DigiKey / Mouser 用 [Chrome 擴展](/zh-Hant/chrome-extension) 看料。
2. 查替代料，點 **CAD models** 或生成 KiCad。
3. 按 [EDA 集成](/zh-Hant/eda-integration) 導入你的工具。

**提問 → 封裝**

1. 在網頁 [Search](/zh-Hant/ai-search) 搜 MPN。
2. 打開器件抽屜 → **CAD Models**，或走 [KiCad 庫生成](/zh-Hant/kicad-library)。
3. 按 [EDA 集成](/zh-Hant/eda-integration) 導入。

**工位 → 桌面**

1. [移動端](/zh-Hant/mobile-app) 識別 marking。
2. 同一 MPN 在網頁 Search 或 Chrome 分銷商頁繼續查。

## 賬號與 Credits

Chrome、網頁、移動端共用同一 PartGenie 賬號與 **Credits**。KiCad 生成與部分 ECAD 下載按套餐計費，見 [會員與定價](/zh-Hant/membership-pricing)。

## 支持站點上的隱私

Chrome 擴展只在支持的分銷商 / 原廠頁面啟用，並使用識別器件所需的頁面資訊。見 [Chrome 擴展](/zh-Hant/chrome-extension#隱私與權限)。
