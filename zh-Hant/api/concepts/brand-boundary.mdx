# API scope

This API is **PartGenie Catalog & Intelligence** — identity, observed market data, resolve / alternatives / BOM risk, and datasheet evidence.

| In scope | Out of scope |
|---|---|
| What is this part? Correct / compatible? | Your sell price or landed quote |
| Observed distributor stock / price | PO, payment, logistics, checkout |
| Claims, engineering profiles, BOM analyze | Full PartGenie Chat transcript / ECAD download API |

Do not send end-customer PII, your sell price, or PO terms into Intelligence APIs.
