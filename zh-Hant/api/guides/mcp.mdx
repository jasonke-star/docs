# MCP

Same capabilities as the REST `/v1` surface, exposed as MCP tools for agent runtimes.

Contact [sales@partgenie.ai](mailto:sales@partgenie.ai) or your Private Beta contact for MCP connection details.

| MCP tool | REST |
|---|---|
| `parts_resolve` | `POST /v1/parts/resolve` |
| `parts_lookup` | `POST /v1/parts/lookup` |
| `parts_get` | `GET /v1/parts/{id}` |
| `parts_offers` | `POST /v1/parts/offers` |
| `parts_alternatives` | `POST /v1/parts/alternatives` |
| `bom_analyze` | `POST /v1/bom/analyze` |
