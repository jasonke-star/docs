## 搜索前

- 有完整 **MPN** 就直接用；否則用「功能 + 最重要的 3 個參數」開頭
- 只有文字說不清時再附加規格書/照片
- 問答用 **Search**；BOM 已上場就切 **Work**

## 結果出現時

- 先看概覽，再點開**引用角標**（MPN / 原廠 / 分銷商 / 頁碼）
- 有實時庫存列時再下采購判斷——Catalog snapshot ≠ Live
- 用追問收緊封裝、溫區或固件約束

## 替代料

- 儘量填寫澄清卡片——上下文好過純參數相似
- 對比控制在 2–5 顆；需要同步他人時導出 Alternative Report

## 效率習慣

- 一條消息一個目標
- 複用 Collection / Knowledge，避免重複上傳同一 PDF
- Pro 可導出表格，少用手工拷貝
